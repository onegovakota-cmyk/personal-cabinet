# Мой личный кабинет

Личное веб-приложение на HTML/CSS/JS + Supabase + GitHub Pages.

## Что внутри

- **Главная:** доходы, расходы, платежи по долгам, свободный остаток.
- **План распределения дохода:** проценты от каждого поступления рассчитываются автоматически.
- **Долги:** автокредит, кредитная карта, кредит на учёбу; прогресс, целевой платёж, редактирование остатка, история платежей.
- **Доходы:** источники и история поступлений.
- **Расходы:** фактические траты и постоянные расходы.
- **Привычки:** свои привычки, отметки на каждый день месяца, прогресс.
- **Задачи:** Работа / Репетиторство / Домашние дела.
- **Вход:** email + пароль через Supabase Auth.
- **PWA:** можно добавить сайт на главный экран телефона.

## Запуск Supabase

1. Откройте ваш проект Supabase.
2. Перейдите **SQL Editor → New query**.
3. Скопируйте весь текст из `supabase.sql`.
4. Вставьте его в SQL Editor и нажмите **Run**.
5. В разделе **Authentication** убедитесь, что включён Email provider.
6. При регистрации приложение может попросить подтвердить email — это нормальное поведение.

`config.js` уже содержит ваш Project URL и **Publishable key**. Secret/service_role key в браузерный проект добавлять нельзя.

## GitHub Pages

1. Создайте новый репозиторий, например `personal-cabinet`.
2. Загрузите в корень все файлы из этой папки.
3. Откройте **Settings → Pages**.
4. Выберите **Deploy from a branch → main → /(root)**.
5. Подождите публикацию и откройте ссылку GitHub Pages.

## Важно про финансовые расчёты

Прогноз по автокредиту использует стандартную формулу аннуитетного платежа на основе текущего остатка, APR и целевой даты. Реальный банк может считать проценты иначе из-за даты платежа, особенностей досрочного погашения и пересчёта графика. Поэтому текущий остаток в приложении можно вручную сверять и корректировать по данным банка.

Для кредитной карты ставка пока неизвестна, поэтому цель 6 месяцев считается без процентов. После ввода реальной ставки расчёт автоматически изменится.
